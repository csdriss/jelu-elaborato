Audit Engine Documentation

This tool enforces deterministic schema validation and data cleaning on incoming HR datasets. It operates entirely client-side, ensuring strict privacy compliance.

Validation Rules

  • Postal Codes: Restores dropped leading/trailing zeroes based on province heuristics.
  • Email Syntax: Detects and repairs missing '@' symbols for internal domains.
  • Compensation (RAL): Normalizes string inputs (e.g., '35k' → 35000) and aggressively corrects decimal shifts (outliers > 200k).
  • Likert Scales (Q1-Q4): Clamps invalid string or numeric entries to the strictly required 1-5 integer scale.
  • NPS (Q5): Normalizes textual numeric representations (e.g., 'nove' → 9) and strictly clamps limits to 0-10.
